## 📋 Overview

This repository contains the technical documentation, code snippets, and test cases used to build the **Universal Interpreter** and **DSA Visualizers** in the Code Tracer Android application.

It details how the `interpretBasicCode` method was upgraded to handle print statements from over 20 different programming languages (C, C++, Java, Python, JS, etc.) using regex and string manipulation.

---

## ✨ Key Implementations

* **🧠 Universal Output Interpreter:** Code that uses regex to extract output from `cout`, `printf`, `System.out.println`, `print()`, and `console.log` across different languages.
* **📝 Test Cases:** A comprehensive table of code snippets for languages like C, C++, Python, Java, Ruby, Go, and more, along with their expected console output.
* **🎮 DSA Visualizers Guide:** Instructions on how to trigger the Array, Stack, and Queue visualizers using specific code syntax in the editor.
